# Эфир под Linux: план (не сделано)

Настольное приложение Linux — тот же код, что и Windows (`desktopApp`, `core`): Kotlin и Compose Desktop.
Отдельного Linux-кода быть не должно; отличается только то, что зависит от системы.

**Состояние: Linux-версия не собиралась и не запускалась ни разу.** Ниже — что уже написано с расчётом на Linux
и что предстоит сделать. Образец — Notio (`v:\projects\notio\docs\LINUX_RU.md`), где Linux-версия уже собирается.

## Что уже написано с расчётом на Linux (не проверено)

| Часть | Как сделано | Где |
| --- | --- | --- |
| Трей и его меню | `Tray` из Compose; где трея нет (GNOME «как есть», WSL), значок не создаётся, а крестик окна закрывает приложение | `desktopApp/.../Main.kt` |

| Адреса в сети | виртуальные адаптеры (docker, virbr, veth, tun, wg…) узнаются по имени и пропускаются | `core/.../net/LocalNetwork.kt` |
| Заголовок окна | на Linux остаётся системный: своя панель-заголовок включается только там, где среда её поддерживает | `WindowChrome.kt` |
| Папка данных | `~/.efir` | `Main.kt` |

## Что сделать

1. **Сборка.** Задачи `packageLinuxDeb`, `packageLinuxPortable` (`.tar.gz`), по возможности `.AppImage` — по образцу
   Notio (`windows/desktopApp/build.gradle.kts`, задачи `releaseLinux`). Копии — в `dist/`. Архивы должны хранить права
   на файлы, иначе `bin/Efir: Permission denied`.
2. **Среда выполнения.** JetBrains Runtime 25 для linux-x64 с `jpackage`; сборка — на Linux или в WSL 2
   (в файловой системе Linux, не в `/mnt/...`).
3. **Значок.** `desktopApp/icons/efir.png` в `linux { iconFile }`, категория меню `Network`.
4. **Папка данных.** Перенести с `~/.efir` на `~/.local/share/efir` (правило XDG), с переездом старой папки.
5. **Трей.** Проверить в GNOME (нужно расширение AppIndicator), KDE, XFCE. Где трея нет — «в трей» должно означать
   «свернуть», а не «закрыть».
6. **Уведомления.** Без трея — через `notify-send`.
7. **Выбор файлов.** `java.awt.FileDialog` на GTK; проверить множественный выбор.
8. **Брандмауэр.** Входящие TCP 47812 и UDP 47813 в `ufw` / `firewalld`: написать в справке, правило само не ставить.
9. **Буфер обмена.** Проверить опрос буфера в X11 и Wayland (в Wayland приложение без фокуса буфер не читает).
10. **Показ экрана ПК и ввод.** `java.awt.Robot` в Wayland не работает: нужен PipeWire / порталы XDG либо честная надпись
    «недоступно в Wayland».
11. **Тесты.** `./gradlew :core:desktopTest` на Linux; тестам нужен дисплей (WSLg даёт его сам).
12. **CI.** Job `linux` на Ubuntu: тесты и `.deb`.

## Чего ждать при первой сборке

- тесты, которые опираются на Windows (пути, окончания строк);
- окончания строк в файлах запуска: `Efir.cfg` должен писаться с окончаниями строк своей системы;
- шрифты и ввод в полях (IME);
- трей и уведомления в конкретном окружении рабочего стола.

Найденное записывать сюда.

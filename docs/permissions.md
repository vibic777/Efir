# Разрешения Android и онбординг

> Все разрешения собраны в приложении на экране **«Настройки» → «Разрешения»**:
> напротив каждого написано, для чего оно нужно, а «Выдать» открывает нужное
> системное окно. Для файлов на Android 11+ это «Доступ ко всем файлам»
> (`MANAGE_EXTERNAL_STORAGE`): без него другое устройство видит пустые папки.

Эфир работает только в локальной сети и требует нескольких разрешений Android.
Часть из них выдаётся через системные диалоги, часть — через специальные экраны
настроек («Специальный доступ»). Ниже — пошаговая инструкция.

## 1. Доступность (инъекция ввода)

Нужна для удалённого управления: тапы, свайпы, мультитач, ввод текста и системные
клавиши (Back/Home/Recents).

**Настройки → Специальные возможности → Установленные приложения → Эфир → Включить.**

Приложение покажет диалог-подсказку, если служба выключена, и умеет открывать
соответствующий экран настроек напрямую.

## 2. Захват экрана (MediaProjection)

Нужен для трансляции экрана телефона на ПК.

Разрешение не запрашивается при запуске. Системный диалог появляется, когда другое
устройство нажимает «Показать экран» (если Эфир свёрнут — приходит уведомление
«Показать экран?», открывающее этот диалог; для него нужно разрешение «Уведомления
приложения»), либо заранее — кнопкой «Разрешить показ экрана» в разделе «Экран» или
строкой «Показ экрана» в «Настройках» → «Разрешения».

На Android 14 и новее разрешение одноразовое: система спрашивает перед каждым показом.
На более старых версиях оно действует, пока приложение запущено. Показ можно остановить
в шторке Android и кнопкой «Остановить показ» в Эфире.

## 3. Уведомления (NotificationListenerService)

Нужен для зеркалирования уведомлений Android на ПК.

**Настройки → Уведомления → Доступ к уведомлениям → Эфир → Разрешить.**

## 4. Файлы

Для доступа к файлам приложение использует разрешения на внешнее хранилище.
На современных версиях Android может потребоваться выдать доступ к «Все файлы»
или выбрать корневые папки (SAF — следующая итерация).

## 5. Камера и микрофон

- **CAMERA** — трансляция камеры телефона (фронтальная/тыловая).
- **RECORD_AUDIO** — передача микрофона.
- Системный звук — через `MediaProjection` (Android 10+).

Разрешения запрашиваются при первом запуске соответствующих функций.

## 6. SMS и звонки

- **READ_SMS / RECEIVE_SMS** — чтение и приём входящих SMS.
- **SEND_SMS** — отправка SMS.
- **READ_PHONE_STATE / READ_CALL_LOG / ANSWER_PHONE_CALLS / CALL_PHONE** — состояние
  звонка, история и управление.
- **Исходящие звонки** с ПК (`callInitiate`) выполняются через `TelecomManager.placeCall`
  и требуют разрешения **CALL_PHONE**.
- Для полноценной отправки SMS (запись в «Отправленные», отчёты о доставке и
  приём `SMS_DELIVER`) требуется роль **приложения SMS по умолчанию**. На
  Android-хосте её можно запросить кнопкой «Сделать SMS по умолчанию» (системный
  диалог `ACTION_CHANGE_DEFAULT`).
- Runtime-разрешения запрашиваются при первом запуске; при отказе функции
  деградируют с понятными сообщениями (без записи в провайдер и отчётов).

## 7. Уведомления приложения (Android 13+)

**POST_NOTIFICATIONS** — для отображения foreground-уведомления трансляции экрана.

## Сводная таблица

| Функция | Разрешение / доступ |
| --- | --- |
| Управление вводом | AccessibilityService |
| Трансляция экрана | MediaProjection (диалог) |
| Зеркалирование уведомлений | NotificationListenerService |
| Файлы | Доступ к хранилищу |
| Камера | CAMERA |
| Микрофон | RECORD_AUDIO |
| Системный звук | MediaProjection (Android 10+) |
| SMS | READ_SMS / RECEIVE_SMS / SEND_SMS |
| Звонки (состояние/история/управление) | READ_PHONE_STATE / READ_CALL_LOG / ANSWER_PHONE_CALLS / CALL_PHONE |
| Исходящие звонки | CALL_PHONE (`TelecomManager.placeCall`) |
| Foreground-уведомление | POST_NOTIFICATIONS (Android 13+) |

## Замечания по приватности

- Соединение только в локальной сети; внешние серверы не используются.
- Доверие устанавливается при сопряжении (одноразовый ключ доступа из 12 символов)
  и может быть отозвано. Устройство без сопряжения не получает ни одной функции.
- Все данные (буфер, уведомления, файлы) передаются лишь доверенному устройству.

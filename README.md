# Эфир
[Русский](README.md) · [English](README.en.md)

**Эфир** — прикладной проект на стадии MVP. Он соединяет мобильное устройство и стационарный компьютер напрямую: чтобы обмениваться, синхронизировать данные и управлять одной стороной с другой. Цель — довести это до спокойного рабочего решения на каждый день. Сейчас Эфир — живой каркас, на котором проверяется, как такая связь должна работать.

Уже можно пробовать связку **Android ↔ Windows** в локальной сети, без интернета и облака: файлы, синхронизация папок, буфер обмена, уведомления, камера и звук, SMS и звонки.

> 🔒 **Канал зашифрован** (с версии 0.3.0): ECDH P-256 на каждое соединение, AES-256-GCM на каждый кадр; ключ доступа и
> токен доверия по сети не передаются. Что проверено, что исправлено и что остаётся риском —
> [`docs/SECURITY_RU.md`](docs/SECURITY_RU.md).

## Стек

- **Kotlin Multiplatform** + **Compose Multiplatform**.
- Общий модуль `core` (KMP): протокол, сеть, discovery, синхронизация, медиа, файлы.
- `androidApp` — приложение для Android (Kotlin + Jetpack Compose, minSdk 26).
- `desktopApp` — приложение для Windows (Compose Desktop, JVM).

Приложения **равноправны**: любое из них может ждать подключение или инициировать его,
транслировать свой экран и принимать чужой, а также ходить в файловую систему
удалённого устройства в обе стороны.

## Требования

- **JDK 17**.
- **Android SDK** (compileSdk 35) для сборки Android-приложения.
- Windows 10/11 для клиента; Android 8.0+ для телефона.

## Сборка и запуск

Общие тесты модуля `core`:

```cmd
gradlew.bat :core:desktopTest
```

Запуск приложения для Windows из исходников:

```cmd
gradlew.bat :desktopApp:run
```

Сборка Android-приложения (debug):

```cmd
gradlew.bat :androidApp:assembleDebug
```

## Упаковка

Разом собрать все релизные артефакты (тесты + Windows + Android):

```cmd
build-release.cmd
```

**Windows (MSI/EXE, с включённой JRE):**

```cmd
gradlew.bat :desktopApp:packageInstaller :desktopApp:packageInstallerExe
```

Готовые релизы копируются в папку `dist\` в корне проекта (она в `.gitignore`): `Efir-<версия>.msi`, `Efir-<версия>.exe`, `Efir-<версия>-windows.zip`, `Efir-<версия>-release.apk`. Версия задаётся в `version.properties` и поднимается перед каждым релизом; файлы прежней версии из `dist\` сборка убирает сама.
Установщик включает JRE — отдельная установка Java не требуется.

**Android (подпись):** ключи лежат в папке `private\` в корне проекта — она в `.gitignore` и в Git не попадает.
Все APK подписывает ключ проекта `private\signing\debug.keystore`; с ним новая сборка ставится поверх старой.
Для отдельного релизного ключа скопируйте
[`androidApp/keystore.properties.example`](androidApp/keystore.properties.example)
в `private\keystore.properties` и заполните
`storeFile`/`storePassword`/`keyAlias`/`keyPassword`, затем выполните:

```cmd
gradlew.bat :androidApp:assembleRelease
```

Без ключа релиз собирается неподписанным (для внутреннего тестирования).
R8/обфускация и `shrinkResources` включены ([`androidApp/proguard-rules.pro`](androidApp/proguard-rules.pro)).

> ⚠️ Неподписанный APK **не устанавливается** на устройство (ошибка «пакет
> недействителен»). Для установки задайте ключ, как описано выше, — тогда
> Gradle подпишет APK автоматически.

**Подпись Windows-инсталляторов:**

```cmd
scripts\sign-windows.cmd
```

По умолчанию создаётся самоподписанный code-signing сертификат (в
`CurrentUser\My`) и подписываются MSI/EXE. Для продакшена передайте свой
сертификат: `scripts\sign-windows.cmd -PfxPath cert.pfx -PfxPassword <pass>`.
Требуется `signtool` (Windows SDK); скрипт находит его автоматически.

## Быстрый старт

1. Установите приложение на телефон и клиент на ПК, подключите их к одной Wi-Fi сети.
2. На телефоне выдайте разрешения для того, чем будете пользоваться («Настройки» → «Разрешения»,
   см. [`docs/permissions.md`](docs/permissions.md)): доступность, уведомления, файлы, камера/микрофон,
   SMS/звонки. Показ экрана заранее выдавать не нужно: телефон спросит сам, когда его попросят показать экран.
3. Сопрягите устройства: на одном нажмите «Показать ключ» (ключ доступа из
   12 символов действует две минуты и годится один раз), на другом — «Сопрячь»
   напротив устройства в списке «Устройства рядом» и введите ключ. Если
   устройства нет в списке, нажмите «Ввести ключ» и укажите его адрес.
4. Дальше устройства подключаются друг к другу кнопкой «Подключиться», без
   ключа и с любой из сторон. Устройство, не прошедшее сопряжение, доступа не
   получает.
5. После подключения доступны: экран, файлы, синхронизация, буфер, уведомления,
   камера/звук, SMS/звонки.

## Интерфейс

Оформление повторяет Notio: зелёная тема Material 3 (светлая и тёмная), шрифт
Roboto, кнопки-значки со всплывающими подсказками. Подсказка появляется, когда
курсор задержался на значке или палец удерживает его; нажатие на подсказку
открывает справку на разделе именно этого элемента. Справка открывается поверх окна
(экран под ней остаётся как был), разложена по вкладкам и разделам, ищется по словам
и показывает найденное в окружении; вверху справки написана версия приложения.

Настройки — меню страниц с поиском: «Общие», «Внешний вид», «Папки», «Показ экрана»,
«Разрешения» (телефон), «Журнал», «О приложении». Папку загрузок, папку для правил
синхронизации и папки, открытые другому устройству, человек выбирает сам — на любом диске.

- Тема, шрифт, знак: [`core/…/ui/theme`](core/src/commonMain/kotlin/ru/efir/core/ui/theme).
- Значки (пути Material Icons, без библиотеки `material-icons-extended`):
  [`AppIcons.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/AppIcons.kt).
- Подсказки и общие элементы: [`Components.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/Components.kt),
  [`TipControls.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/TipControls.kt).
- Справка: разделы и поиск — [`Help.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/Help.kt), тексты —
  `HelpTextsRu.kt` и `HelpTextsEn.kt` рядом со строками интерфейса.
- Справка и её разделы: [`Help.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/Help.kt).
- Экраны: [`core/…/ui/screens`](core/src/commonMain/kotlin/ru/efir/core/ui/screens).

**Языки.** Русский и английский; выбор — в «Настройках», по умолчанию язык
системы. Все тексты лежат в
[`Strings.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/i18n/Strings.kt)
(русские значения — основа). Новый язык — это наследник `Strings` по образцу
[`StringsEn.kt`](core/src/commonMain/kotlin/ru/efir/core/ui/i18n/StringsEn.kt)
и одна строка в `enum Lang`; непереведённое остаётся русским. Сообщения об
ошибках, которые формирует ядро (сеть, файлы), пока только на русском.

**Новая функция** получает тем же шагом: подсказку на каждом значке
(`IconAction`), тексты на обоих языках и место в справке — абзац в тексте
раздела и значок со словами в `HelpTopic`.

## Качество видео и адаптивный битрейт

Потоки экрана и камеры по умолчанию передаются как JPEG-кадры. Клиент задаёт
разрешение, целевой FPS, `bitrate` и `jpegQuality`; при включённом флаге `adaptive`
(по умолчанию) хост автоматически снижает/повышает качество под фактическую
пропускную способность сети (см. [`docs/protocol.md`](docs/protocol.md)).

**Аппаратное кодирование (opt-in).** При запросе `codec = "h264"` хост кодирует
видео через `MediaCodec` (Surface-кодирование), а ПК декодирует его чистым
JVM-декодером (JCodec + Skia). Если устройство не поддерживает аппаратное
Surface-кодирование, автоматически используется JPEG-путь. Классы:
[`AndroidH264Encoder`](core/src/androidMain/kotlin/ru/efir/core/media/H264Encoder.android.kt),
[`VideoDecoding`](core/src/commonMain/kotlin/ru/efir/core/media/VideoDecoding.kt).

**Профилирование.** Хосты и клиенты считают фактический FPS, битрейт и оценку
задержки «захват → обработка» ([`StreamMetrics`](core/src/commonMain/kotlin/ru/efir/core/media/StreamMetrics.kt));
значения доступны в состояниях потоков (`actualFps`, `latencyMs`, `bitrateBps`,
`measuredBps`).

**Энергопотребление.** Во время соединения foreground-сервис телефона удерживает
частичный `WakeLock`; исключение из оптимизации батареи (Doze) приложение само не
запрашивает — это строка «Работа в фоне» в разрешениях. Компьютер снимает свой экран,
только пока его смотрят: не чаще 12 кадров в секунду и не отправляя кадр, который не
изменился. Правила — в [`docs/BATTERY_RU.md`](docs/BATTERY_RU.md).

## Ограничения

- Без root часть системных экранов и защищённый контент (DRM) недоступны.
- Захват системного звука — Android 10+; часть приложений запрещает захват.
- Фоновый доступ к буферу обмена на Android 10+ ограничен.
- Для отправки SMS/полного доступа может потребоваться роль default SMS app.

# План 09 — UI настроек синхронизации и управления

## Цель

Создать удобный интерфейс управления синхронизацией: создание правил, выбор папок, настройка стратегий, просмотр статуса и разрешение конфликтов.

## Зависимости

[`plans/08-sync-engine.md`](08-sync-engine.md)

## Экраны

- **Список правил синхронизации:** имя, пара папок, направление, расписание, статус (on/off), последняя синхронизация.
- **Редактор правила:**
  - выбор локальной и удалённой папок;
  - направление (двусторонняя/в одну сторону);
  - триггер (вручную/расписание/подключение/changes);
  - фильтры включения/исключения (маски, размер, тип);
  - стратегия конфликтов (слияние/замещение/добавление/приоритет/переименование);
  - опции удаления/бэкапа.
- **Монитор синхронизации:** очередь, прогресс, скорость, текущие операции.
- **Конфликты:** список конфликтующих файлов с предпросмотром и выбором «оставить ПК / оставить телефон / оба (переименовать) / пропустить».
- **Журнал:** история операций с фильтрами и возможностью отката из версий.

## UX-детали

- Индикаторы направления стрелками (↔, →, ←).
- Пресеты стратегий («Безопасное объединение», «Зеркало ПК → телефон», «Только добавление»).
- Предпросмотр, что будет сделано (dry-run) перед применением.
- Уведомления о завершении/конфликтах.

## Шаги реализации

1. Реализовать список и редактор правил (Compose).
2. Реализовать выбор папок (интеграция с файловыми деревьями обеих сторон).
3. Реализовать UI триггеров и расписания.
4. Реализовать UI фильтров и стратегий.
5. Реализовать монитор синхронизации в реальном времени.
6. Реализовать экран разрешения конфликтов.
7. Реализовать экран журнала и отката.

## Краевые случаи

- Некорректные пути (вложенные пары папок) — предупреждать.
- Правило с недоступной удалённой папкой — статус «ошибка».
- Большие списки конфликтов — фильтрация и массовые действия.

## Критерии готовности

- [x] Создание/редактирование/включение правил синхронизации.
- [x] Настройка триггеров, фильтров и стратегий (диалог `SyncRuleEditor`).
- [x] Монитор прогресса и dry-run плана (`SyncRunStatus`, предпросмотр действий).
- [x] Разрешение конфликтов вручную (кнопки «Оставить ПК/тел./Оба/Пропустить»).
- [x] Экран отката из журнала (история версий + восстановление, см. итерацию 2).

## Что реализовано (итерация 1)

- Секция [`SyncSection`](core/src/commonMain/kotlin/ru/efir/core/app/EfirAppScreen.kt)
  в общем экране: список правил, создание/редактирование, включение/выключение,
  удаление, ручной запуск, предпросмотр (dry-run) и журнал.
- Диалог [`SyncRuleEditor`](core/src/commonMain/kotlin/ru/efir/core/app/EfirAppScreen.kt):
  имя, папки, направление, триггер (+интервал расписания), стратегия конфликтов,
  include/exclude-маски, распространение удалений.
- Монитор: прогресс `processed/total`, текущий путь, итоговое сообщение.
- Предпросмотр плана: количество действий/конфликтов и первые 10 действий.
- Разрешение конфликтов: список конфликтов с кнопками по каждому и массовое
  «оставить новейшие»; поддерживаются выборы `KEEP_LOCAL`/`KEEP_REMOTE`/
  `KEEP_NEWEST`/`KEEP_BOTH`/`SKIP` через
  [`EfirController.resolveSyncConflicts`](core/src/commonMain/kotlin/ru/efir/core/app/EfirController.kt).

## Что реализовано (итерация 2)

- **История версий/откат** в [`SyncSection`](core/src/commonMain/kotlin/ru/efir/core/app/EfirAppScreen.kt):
  кнопка «История» у каждого правила загружает список резервных версий
  (`EfirController.syncVersions`), отображает время (UTC), путь, размер и сторону;
  кнопки «Восстановить» (`restoreSyncVersion`), «Обновить» и «Очистить историю»
  (`clearSyncVersions`). Формат времени — [`formatTimestamp`](core/src/commonMain/kotlin/ru/efir/core/app/EfirAppScreen.kt).

## Что реализовано (итерация 3)

- **Пресеты стратегий**: [`SyncPreset`](core/src/commonMain/kotlin/ru/efir/core/sync/SyncPresets.kt)
  («Безопасное объединение», «Зеркало ПК → телефон», «Зеркало телефон → ПК»,
  «Только добавление», «Спрашивать о конфликтах») — одним действием задают
  направление, стратегию конфликтов, распространение удалений и бэкап;
  `SyncPreset.applyTo(config)` сохраняет id/имя/пути/триггер.
- **Подсказки направления**: [`directionHint`](core/src/commonMain/kotlin/ru/efir/core/sync/SyncPresets.kt)
  (стрелка + пояснение «только с ПК на телефон» и т.п.).
- **UI** [`SyncRuleEditor`](core/src/commonMain/kotlin/ru/efir/core/app/EfirAppScreen.kt:1224):
  список кнопок-пресетов и строка-подсказка направления; добавлен переключатель
  «Бэкап перед перезаписью».
- **Тесты**: [`SyncPresetsTest`](core/src/commonTest/kotlin/ru/efir/core/sync/SyncPresetsTest.kt).

## Что реализовано (итерация 4)

- **Пакетные операции над конфликтами**: в [`SyncSection`](core/src/commonMain/kotlin/ru/efir/core/app/EfirAppScreen.kt)
  добавлены массовые кнопки «Все: ПК / тел. / новейшие / оба / пропустить» —
  одним действием применяют выбранную стратегию ко всем конфликтам правила
  (хелпер `applyToAllConflicts`).
- **Версии конкретного файла**: кнопка «Только этот файл» у каждой версии
  фильтрует историю по пути (через [`EfirController.fileVersions`](core/src/commonMain/kotlin/ru/efir/core/app/EfirController.kt)),
  добавлена кнопка «Показать все файлы».
